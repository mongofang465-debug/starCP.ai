# AI Celebrity Relationship Analyst

## ❤️ AI 明星婚恋分析师

AI Celebrity Relationship Analyst is an entertainment app that analyzes the romantic compatibility and relationship tendencies of public figures.

Users can enter one celebrity or two celebrities, and the AI will generate a detailed relationship analysis report based on publicly available information and behavioral patterns.

---

## 功能介绍 | Features

### 👤 单人分析模式

输入一位明星姓名。

AI 将从多个维度分析其潜在择偶倾向：

* 年龄
* 教育背景
* 家庭背景
* 职业发展
* 财富与社会地位
* 性格特征
* 公开恋爱经历
* 婚姻观推测
* 未来家庭结构倾向

输出内容包括：

* 理想伴侣画像
* 可能偏好的年龄区间
* 可能偏好的职业类型
* 婚姻稳定性分析
* 家庭结构预测
* 潜在情感风险

---

### 💕 双人CP分析模式

输入两位明星姓名。

AI 将分析：

* 性格匹配度
* 三观匹配度
* 事业发展兼容性
* 家庭背景匹配度
* 财富观匹配度
* 婚姻稳定性
* 长期关系风险
* 子女教育观预测
* 家庭权力结构预测

输出内容包括：

* CP匹配评分
* 恋爱发展预测
* 婚姻发展预测
* 潜在危机分析
* 长期相处建议

## Security

API keys are stored securely on the server side and are never exposed to the frontend.

Recommended methods:

* Environment Variables
* Streamlit Secrets
* Backend API Proxy

Never expose API keys in frontend code.
